# Contributor Covenant Code of Conduct

We are committed to providing a welcoming, respectful, and harassment-free experience for everyone participating in **GarlicDiffusion**, regardless of experience level, background, or console hardware.

## Expected Behavior
- Be constructive, patient, and respectful in issues, pull requests, and discussions.
- Respect upstream authors, model creators, and open-source licenses (including GPLv3 attribution).
- Keep all shared showcase imagery, prompts, and discussions in this repository **strictly SFW**.

## Unacceptable Behavior
- Harassment, personal attacks, trolling, or discriminatory remarks.
- Sharing NSFW/explicit imagery in issues, PRs, or gallery submissions.
- Sharing pirated Sony SDKs, copyrighted game dumps, or unauthorized firmware files.

Maintainers reserve the right to edit or remove comments, issues, or PRs that violate this Code of Conduct.
