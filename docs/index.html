Built From Scratch for PS4 GCN

Because PS4 homebrew has no CUDA, PyTorch, or Vulkan compute runtime, the entire inference engine compiles 22 zero-scratch GCN OpenCL kernels dispatched directly via hand-written PM4 command packets.

Hardware CU Thermal Control

Symmetric checkerboard SH_STATIC_THREAD_MGMT CU masks (14 / 20 / 25 / 36 CUs on Pro; 7 / 11 / 14 / 18 CUs on Base PS4) + inter-block breathers prevent jet-engine fan spikes.

Built-In 1080p AI Upscaler

Bundled Real-ESRGAN Anime v3 (2.4 MiB) runs natively on PS4 GPU, turning 512×768 into crisp 1080×1620 in 8.2 seconds.

In-App Hugging Face Downloader

Stream pre-converted PSD1 models straight onto your PS4 HDD over HTTPS with resume support, live MB/s progress, and zero FTP required.

Web Studio, Gallery & Styles

Full LAN Web UI on port 8081 with Save Prompt, Reusable Art Styles, 1:1 Lightbox Gallery, Resize/Upscale, and JSON Preset Export/Import.

A1111 PNG Info & Discord API

Embeds standard Automatic1111 tEXt parameters into every PNG and serves /sdapi/v1/txt2img (works with bz-cogs/aimage) + OpenAI /v1/images/generations.

Base PS4, Slim & PS4 Pro

Auto-switches to compact 325 MiB scratch buffers on Base/Slim PS4 so both SD 1.5 (1.5 GiB) and full SDXL (4.0 GiB) fit in direct memory.

Quick Install & API

1. Install the 6.6 MiB PKG

Install Garlic-Diffusion.pkg on any GoldHEN PS4 / PS4 Pro via Package Installer, then launch it from the home screen.

2. Download a Model In-App

Open http://<PS4_IP>:8081 → Models tab (or press [Up] on your controller) and click Download to PS4.

3. Connect Discord or A1111

Point Automatic1111 clients or bz-cogs/aimage at http://<PS4_IP>:8081 — no extra setup needed.

curl http://192.168.1.29:8081/sdapi/v1/txt2img \
  -H "Content-Type: application/json" \
  -d '{"prompt":"masterpiece, best quality, 1girl, silver hair, glowing sakura","steps":6,"cfg_scale":1.0,"width":768,"height":1024,"sampler_name":"LCM"}'
