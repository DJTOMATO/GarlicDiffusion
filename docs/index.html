What It Does

Everything runs locally on your PlayStation 4. Nothing is sent to the cloud.

Dual SD 1.5 & SDXL GCN Engine

22 custom bare-metal OpenCL GCN kernels dispatched via raw PM4 command packets. Supports LCM, Euler, Euler a, and DPM++ 2M Karras samplers plus A1111 (tag:weight) prompt weighting in 1.5–1.7 GiB (SD 1.5) or 4.0–4.2 GiB (SDXL).

Built-In 1080p & 4K AI Upscaler

Ships with Real-ESRGAN AnimeVideo v3 (2.4 MiB) inside the PKG. Upscales images to crisp 1080p Full HD in 8.2–16.8s, or up to 4K UHD (3840×2160) on PS4 Pro.

80+ Built-In Presets, Styles & Characters

Comes seeded with 20 Prompt Presets, 22 reusable Art Styles (Shinkai, Ghibli, 2D DreamShaper Fix, Manga, Ukiyo-e), and 38 Character Presets (Miku, Frieren, Rem, Saber, Hololive, Genshin, FFVII) on both TV and Web UI.

Hardware CU Thermal Scaling

4 live GPU power modes (Silent 14CU, Quiet 20CU, Balanced 25CU, Turbo 36CU) using symmetric checkerboard SH_STATIC_THREAD_MGMT masks + thermal cooldown breathers to keep your PS4 cool and quiet.

1-Click Hugging Face Downloader

Stream pre-converted PSD1 models directly onto your PS4 HDD over HTTPS (libSceHttp + libSceSsl) from DJTomato/ps4-diffusion-models — zero FTP required. Want another model converted? Request it in our Support Discord!

A1111 PNG Info, Web Studio & Discord API

Full LAN Web Studio on port 8081, standard Automatic1111 tEXt metadata embedded in every PNG, plus drop-in /sdapi/v1/txt2img for bz-cogs/aimage Discord bots and OpenAI clients.

Install in Three Steps

1. Install the 7.0 MiB PKG

Download Garlic-Diffusion.pkg from GitHub Releases and install it on any GoldHEN PS4, PS4 Slim, or PS4 Pro via GoldHEN → Package Installer.

2. Download a Model In-App

Launch GarlicDiffusion. Press [OPTIONS] on your controller (or select Model → Download / Manage with [X], or open http://<PS4_IP>:8081 → Models) and download MeinaMix_V11_8step or WAI_Illustrious_v17_dmd2.

3. Generate on TV, Phone, or Discord

Navigate settings with D-Pad / Stick, open dropdowns & sliders with [X] / cancel with [O], and press [Triangle] to generate — or use the LAN Web Studio and Discord API on port 8081.

Questions

Does it need internet or a PC while generating?

No. Once you download a model onto the console's drive, CLIP text encoding, UNet denoising, VAE decoding, and Real-ESRGAN 1080p/4K upscaling all run 100% offline on the PS4's own GPU.

Does it work on a Base PS4 / PS4 Slim, or only PS4 Pro?

It works on all three! On a Base PS4 or PS4 Slim (18 CUs, 4.0 GiB direct memory), GarlicDiffusion automatically enables a compact 325 MiB activation scratch layout and 24×24 tiled VAE decoding so both SD 1.5 (1.54 GiB, recommended for speed!) and full SDXL (4.04 GiB) fit cleanly.

Why is it called "GarlicDiffusion"?

On the PlayStation 4's unified GDDR5 memory architecture, Sony's internal codename for the high-bandwidth memory bus that the GPU reads directly is "Garlic" (paired with the CPU-coherent bus, "Onion"). The name also honors Leonardo Alegría's Garlic LLM, which pioneered bare-metal PM4 GPU AI on the PS4.

Can it overheat or harm my console?

GarlicDiffusion is an ordinary userland homebrew app and contains no exploit. However, diffusion inference drives sustained GPU load on 7–13 year old hardware. That is why GarlicDiffusion defaults to Quiet Mode (20 of 36 CUs on Pro · ~58% GPU power) with automatic inter-block thermal cooldown pauses. Always keep your console's vents unobstructed and use Quiet or Silent (14 CU) mode for long sessions.

Why did DreamShaper 8 look semi-realistic / 2.5D on anime characters?

Unlike pure 2D anime checkpoints (MeinaMix, Anything V5, WAI-Illustrious), DreamShaper 8 is trained on painterly 2.5D portraits. Selecting the built-in "2D Anime Fix (For DreamShaper)" Art Style in Studio adds cel-shading tags and suppresses 3D/photorealistic skin shading — while DreamShaper 8 shines naturally on fantasy landscapes.
